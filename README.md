
# 💬 Chat Application Using Socket Programming

## 📌 Project Overview

This project is a Python-based Chat Application developed using Socket Programming. It demonstrates communication between a client and a server over a network.

The project includes Python socket communication, server-side functionality, and web interface components.

## 🚀 Features

- Client-server communication
- TCP socket programming
- Message transmission over a network
- Python-based implementation
- Web interface components using HTML, CSS, and JavaScript
- Simple project structure

## 🛠️ Technologies Used

- Python
- Socket Programming
- TCP/IP Protocol
- HTML
- CSS
- JavaScript

## ⚙️ Installation

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Chat-Application-Using-Sockets.git
```

### Step 2: Open the Project Folder

```bash
cd Chat-Application-Using-Sockets
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

### Start the TCP Server

```bash
python tcp_server.py
```

### Start the Client

Open another terminal:

```bash
python client.py
```

### Run the Web Application

```bash
python app.py
```

Note: Run the relevant components according to your application's configuration.
